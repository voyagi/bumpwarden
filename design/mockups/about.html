Where the machine stops

One Cloud Run service carries both the dashboard and the run endpoint, so the scheduled run and the page a visitor opens are the same deployment. The model sits on a spur off the main line. It reads, it explains, and the spur ends there: it holds no GitHub tool and it cannot reach the actor.

git clone git@github.com:voyagi/bumpwarden.git && cd bumpwarden
cp .env.example .env  # GEMINI_API_KEY, GITHUB_TOKEN, FIRESTORE_PROJECT_ID
npm ci && npm run dev  # http://localhost:8080, Firestore emulator
gcloud run deploy bumpwarden --region europe-west1 --source .

The full step by step, including the Cloud Scheduler job, the invoker service account and the Secret Manager entries, is in README.md.
