# Mockups

Hi-fi mockups of all six pages, built to [../ART-DIRECTION.md](../ART-DIRECTION.md). Open any
`.html` file directly, or serve the folder. They share `signalbox.css`, which is the source of the
design tokens the app itself uses.

The content is real: package names, versions and publish dates come from the npm registry, and the
Express 5 quotes come from the
[official migration guide](https://expressjs.com/en/guide/migrating-5.html). Nothing here is
placeholder copy.

One artifact to know about when reading the mobile shots: below 900px the lever rail is a sticky
bottom bar, and a full page screenshot renders a sticky element wherever the capture scrolled to,
so it appears mid page in the image. In a real viewport it sits on the bottom edge.
